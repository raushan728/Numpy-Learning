# NumPy Practice

This repository contains my practice and learning progress on NumPy — the powerful numerical computing library in Python. The focus is on core concepts that are frequently used in real-world data science, machine learning, and EDA workflows.

---

## ✅ Covered Topics

### 📘 Array Creation
- 1D, 2D arrays using `np.array()`
- `reshape()` and `-1` trick
- Size mismatch error handling

### 📗 Indexing & Slicing
- Accessing specific elements
- Row/column slicing in 2D arrays
- Boolean indexing

### 📙 Random Number Generation
- `np.random.randint()`
- `np.random.rand()`, `randn()`
- `np.random.choice()` (with and without replacement)
- `np.random.seed()` for reproducible results

### 📕 Important NumPy Functions
- `np.unique()`
- `np.where()`
- `np.stack()`, `np.vstack()`, `np.hstack()`
- Axis concept in `np.sum()`, `np.mean()` etc.
- Math functions: `min`, `max`, `std`, `mean`, etc.

## 📦 Requirements

Make sure the following are installed:

- Python 3.x
- NumPy
- Jupyter Notebook (optional, for better practice)

### 🔧 Installation

#### Step 1: Install Python (if not already)
Download from: https://www.python.org/downloads/

#### Step 2: Install NumPy
```bash
pip install numpy
```

#### Step 3: (Optional) Install Jupyter Notebook
```bash
pip install notebook
```

#### OR, install all using Anaconda (recommended)
```bash
conda install numpy notebook
```
